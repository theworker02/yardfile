# yardfile

Yard structured JSON file payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/yardfile/

## Install / run

```bash
git clone https://github.com/theworker02/yardfile.git
cd yardfile
node src/cli.js
node --test
```
